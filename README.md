**Lambda expressions:** a small, anonymous function that is defined without a name and can only contain a single expression.

**First-Class Citizens:** In Python, functions are treated as standard data types, meaning they can be passed as arguments, returned by other functions, and stored within data structures.

**Higher-Order Functions:** These are dynamic functions that operate directly on other functions to modify, combine, or enhance their behavior. --> a function that either takes one or more functions as arguments, returns a function as its result, or 

**Closures:** These are functions capable of "remembering" and capturing variables from the specific environment in which they were created, allowing those variables to persist beyond their original scope.

**The nonlocal Keyword:** This keyword is utilized within closures to maintain and update a private, persistent state across multiple function calls without relying on forbidden global variables.
